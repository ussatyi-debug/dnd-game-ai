# DnD Game AI

Текстовая игра по правилам D&D 5e (2014), где мастером выступает ИИ, а правила, броски и
состояние ведёт программный движок. Платформы: Windows (`.exe`) и Android (`.apk`).

**Принцип:** ИИ рассказывает, движок считает. Значения кубов, модификаторы, расход ресурсов и
проверки выполняет код на Rust; ИИ только запрашивает действия и описывает результат.

## Структура

```
crates/engine/   движок на Rust (без внешних зависимостей, сериализация — по флагу serde)
  src/rng.rs       генератор случайных чисел (xoshiro256**, выбор грани без смещения)
  src/expr.rs      выражения бросков: 2d6+3, 8d6, 1d8+5+2d8, 2к6+3; удвоение кубов на крите
  src/check.rs     d20: преимущество/помеха, модификаторы с подписями, порог крита, атаки
  src/notation.rs  заявки игрока: «16», «12 - везунчик», «нат 20»
  src/resource.rs  пулы ресурсов и восстановление на коротком/длительном отдыхе
src-tauri/       приложение Tauri 2: команды, связывающие интерфейс с движком
src/             интерфейс React + TypeScript + Tailwind CSS
```

## Запуск на ПК

Нужны: [Rust](https://rustup.rs), [Node.js 22](https://nodejs.org) и
[требования Tauri для Windows](https://tauri.app/start/prerequisites/) (WebView2, MSVC Build Tools).

```bash
npm install
npm run tauri dev      # запуск в режиме разработки
npm run tauri build    # установщик: target/release/bundle/nsis/
```

Тесты движка:

```bash
cargo test -p dnd-engine
```

## Сборки

Каждый пуш в `main` проверяется в GitHub Actions: согласованность версий, форматирование,
линтер и тесты движка, проверка типов и сборка интерфейса, сборка установщика Windows.

Если версия ещё не выпускалась, после успешной сборки автоматически создаются тег `vX.Y.Z` и
релиз с установщиком — он доступен на странице **Releases**. Чтобы выпустить новую версию,
поднимите её одновременно в `Cargo.toml` (`[workspace.package]`), `package.json` и
`src-tauri/tauri.conf.json`.

## Правила разработки

- Ветка `main` всегда рабочая; новая функциональность — в отдельной ветке.
- Сообщения коммитов в формате Conventional Commits: `feat: ...`, `fix: ...`, `test: ...`.
- Рабочие версии помечаются тегами `vX.Y.Z` (их ставит CI) — к ним можно откатиться.
- Найти коммит, который что-то сломал: `git bisect`; отменить его: `git revert <коммит>`.

## Лицензии контента

Механики основаны на System Reference Document 5.1 (Wizards of the Coast LLC), доступном по
лицензии [CC-BY-4.0](https://creativecommons.org/licenses/by/4.0/).

Каталог заклинаний (`data/spells`) собран из SRD 5.1: структурированные данные взяты из проекта
[5e-bits/5e-database](https://github.com/5e-bits/5e-database) (MIT), русский перевод описаний
выполнен для этого проекта. Пять заклинаний вне SRD (Доспех Агатиса, Вызывание страха, Теневой
клинок, Голод Хадара, Водяная стена) описаны своими словами — только механика, без текста книг.
После правки данных запустите `npm run spells`, чтобы обновить сгенерированные каталоги для
интерфейса и движка; CI проверяет, что они не устарели.
