Наследие дома Стрэндж

Текстовая ролевая игра по D&D 5e с ИИ-мастером. Инструкция для игрока.

Пароль слоя мастера

Слой мастера в базе знаний (тайны, планы NPC, таймеры) закрыт паролем. Пароль по умолчанию: 413386

Свой пароль можно задать в базе знаний (кнопка «Сменить пароль» в слое мастера). Свой пароль хранится только на этом устройстве; кнопка «Вернуть пароль по умолчанию» снова включает пароль выше.

Подключение ИИ-мастера

  • Меню → Настройки → ИИ: выберите провайдера (Claude, OpenAI, Gemini, Яндекс или локальная модель Ollama) и введите свой ключ.
  • Ключ хранится только на вашем устройстве и отправляется только выбранному провайдеру.
  • Локальная модель Ollama: адрес http://<IP компьютера>:11434.

Озвучка

Меню → Настройки → Озвучка. Вкладки движков:

  • Piper — без интернета. Голоса Дмитрий и Ирина встроены; Денис и Руслан скачиваются там же (около 63 МБ каждый).
  • Silero — встроен в версию для Windows, без интернета. Первая фраза после запуска — несколько секунд (загрузка модели).
  • Свой сервер — озвучка с компьютера в домашней сети (см. ниже).
  • OpenAI, Gemini, Яндекс — облачные голоса тем же ключом, что у мастера; нужен интернет, фразы оплачиваются по тарифу провайдера. Для Яндекса сервисному аккаунту нужна роль ai.speechkit-tts.user.

Озвучка Silero на телефоне (свой сервер)

Шаг 1. Включите раздачу на ПК. На компьютере с Windows: Настройки → Озвучка → Silero → «Раздавать озвучку в домашнюю сеть». Там же показан адрес, например http://192.168.0.5:5150.

Шаг 2. Откройте доступ в брандмауэре Windows.

  • Параметры → Сеть и Интернет → ваша сеть (Wi-Fi или Ethernet) → тип профиля «Частная».
  • Откройте PowerShell от имени администратора и выполните:
New-NetFirewallRule -DisplayName "DnD Game AI озвучка" -Direction Inbound -Protocol TCP -LocalPort 5150 -Action Allow -Profile Private,Public

Шаг 3. Проверьте адрес ПК. В командной строке выполните ipconfig и найдите «IPv4-адрес» у адаптера Wi-Fi или Ethernet (не у VPN, VirtualBox, Hyper-V или WSL). Если он отличается от показанного в игре — используйте адрес из ipconfig.

Шаг 4. Проверьте связь.

  • На ПК откройте в браузере http://localhost:5150/voices — должен появиться список голосов.
  • На телефоне откройте в браузере http://<IP ПК>:5150/voices. Если список есть — в игре на телефоне: Настройки → Озвучка → «Свой сервер» → адрес → «Подключить».
  • На ПК список есть, а на телефоне нет — мешает брандмауэр или роутер. Отключите в роутере «изоляцию клиентов» (AP isolation) или не используйте гостевую сеть.

Свой сервер без версии для Windows

Любой компьютер с Python 3.10+ (Linux, macOS, Windows):

pip install --index-url https://download.pytorch.org/whl/cpu torch
pip install silero silero-stress omegaconf
python silero_server.py

Файл silero_server.py лежит в папке игры (подпапка tools рядом с программой) — скопируйте его на тот компьютер. Порт по умолчанию 5150; другой — python silero_server.py 6000.

Сохранения

  • Автосохранение — после каждого хода мастера, 5 последних по кругу.
  • Меню → Сохранить: 10 ручных ячеек, сохранение в файл (папка «Загрузки») и в буфер обмена.
  • Сейв из файла загружается в свою ячейку «Из файла · День N» и не пропадает после «Новой игры».
